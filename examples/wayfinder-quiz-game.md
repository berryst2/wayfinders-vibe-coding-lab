# Example app idea: Wayfinder Quiz Game

**Best for:** students who like games, competition and instant feedback.

## App brief

- **App name:** StarPath Quiz
- **Audience:** Year 9 and 10 students
- **Purpose:** Teach people about navigation, stars and STEM through a quiz
- **Theme:** Finding your way using the sky and the ocean
- **Design vibe:** Night sky, deep blue, bright stars
- **Feature 1:** A welcome screen with a start button
- **Feature 2:** Five multiple choice questions
- **Feature 3:** A score counter and a final result message
- **Interactive feature:** The quiz itself

## Starter prompt

```
Build me a simple quiz game web app about navigation and STEM.

The quiz should have five multiple choice questions, one at a time,
a score counter, feedback after each answer, and a final result screen
with a play again button.

Use a night sky colour theme with deep blues and bright accents.
Keep the code beginner friendly with comments.
Use only HTML, CSS and JavaScript.
```

## Follow-up prompts

```
Add a progress bar showing which question I am on.
```

```
Make the correct answer flash green and the wrong answer flash red.
```

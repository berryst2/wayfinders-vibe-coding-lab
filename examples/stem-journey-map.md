# Example app idea: My STEM Journey Map

**Best for:** students who want something personal and reflective.

## App brief

- **App name:** My STEM Journey
- **Audience:** Me, my whānau and my class
- **Purpose:** Show where I am now and where STEM could take me
- **Theme:** A journey with steps, like a voyage
- **Design vibe:** Bright, hopeful, colourful
- **Feature 1:** A title with my name
- **Feature 2:** Five journey steps from school to future career
- **Feature 3:** Each step reveals a short message when selected
- **Interactive feature:** Step-by-step reveal

## Starter prompt

```
Build me a web app called "My STEM Journey".

It should show five journey steps laid out in order. When I select a step,
it reveals a short message about that stage of my journey.

Use bright, hopeful, colourful styling. Keep the code beginner friendly
with comments. Use only HTML, CSS and JavaScript.
```

## Follow-up prompts

```
Animate each step so it fades in when I select it.
```

```
Add a final step called "Where I am heading" with a bigger highlight style.
```

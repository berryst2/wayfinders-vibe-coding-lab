# Example app idea: Cultural Knowledge Keeper

**Best for:** students who want to share a story, a word, a place or something meaningful.

## App brief

- **App name:** Knowledge Keeper
- **Audience:** My classmates and my family
- **Purpose:** Share words, meanings and stories so they are not forgotten
- **Theme:** Passing knowledge from one generation to the next
- **Design vibe:** Warm, earthy, calm
- **Feature 1:** A welcome section explaining why this knowledge matters
- **Feature 2:** Knowledge cards you select to reveal the meaning
- **Feature 3:** A "add your own" note section
- **Interactive feature:** Click to reveal

## Starter prompt

```
Build me a simple Cultural Knowledge Keeper web app.

It should show a grid of cards. Each card has a word, a place, or an idea.
When someone selects a card, it reveals a short explanation underneath.

Use warm, earthy colours. Keep the code beginner friendly with comments.
Use only HTML, CSS and JavaScript, and update index.html, style.css and script.js.
```

## Follow-up prompts

```
Add a search box that filters the cards as I type.
```

```
Add a footer that credits the people who shared this knowledge with me.
```

How students can build their own app

This project is a starter for students who want to create a small web app, quiz, game, story page, or learning tool using HTML, CSS, and JavaScript. You do not need to be an expert, and you do not need to install anything. You just need a clear idea and a little patience.

💡Pick an idea → 🔑Sign up → 📥Copy the code → 💻Open Codespaces → 🤖Vibe code with Copilot → 🧪Test it → 🚀Publish → 📣Share

Prerequisites

Before you start, make sure you have:

  • A computer, Chromebook, or tablet with a modern web browser (Chrome, Edge, or Firefox)
  • An internet connection
  • A free GitHub.com account (Step 1 below)
  • Access to GitHub Copilot (through your school, GitHub Education, or GitHub Copilot Free)
  • About 45–60 minutes

Nothing needs to be installed. All the coding happens in the browser using GitHub Codespaces.

1Create your GitHub.com account

  1. Go to github.com/signup.
  2. Enter your email address, create a password, and choose a username.
  3. Verify your email using the code GitHub sends you.
  4. If your school provides GitHub Education or Copilot access, ask your teacher for sign-up instructions so Copilot is enabled on your account.

Already have an account? Sign in and skip ahead to Step 2.

2Get your own copy of this project

  1. Open this repository on GitHub.
  2. Select the green Use this template button (or Fork if that option is shown instead).
  3. Choose Create a new repository.
  4. Give your copy a short name, for example my-wayfinders-app.
  5. Set the visibility to Public — this is required for free GitHub Pages publishing later.
  6. Select Create repository.

You now have your own copy of the project. Every change you make from here happens in your copy, not the original.

3Open your project in GitHub Codespaces

  1. In your new repository, select the green Code button.
  2. Select the Codespaces tab.
  3. Select Create codespace on main.
  4. Wait about a minute while your coding environment loads in the browser.
  5. You should see index.html, style.css, script.js, and the prompts folder in the file list on the left.
  6. Select the Ports tab at the bottom, find port 8080, and select the globe icon to preview your app in a new tab.

Codespaces gives you a full coding environment inside your browser tab. There is nothing to install on your own computer.

4What is “vibe coding”?

Vibe coding means describing what you want in plain English and letting GitHub Copilot write the HTML, CSS, and JavaScript for you. You focus on the idea and the experience. Copilot focuses on the code. You still read the result, test it, and ask for changes until it feels right.

You: Build a quiz about navigation with a score counter.
Copilot: Updates index.html, style.css, and script.js, then explains what changed and what to test.
You: Make the score bigger and add a restart button.
Copilot: Adjusts the styles and adds the restart feature.

Open Copilot Chat in Codespaces (the chat icon in the left sidebar) to start a conversation like this one.

5Choose your build prompt

Open the prompts folder and pick one scenario. Each file has a ready-to-use prompt: open it, copy the whole grey code block, and paste it into Copilot Chat.

6Iterate like a real developer

Your first version will not be perfect, and that is normal. Use small, focused prompts to improve it.

  1. Refresh your preview tab after every change.
  2. Ask for one improvement at a time, for example colours, spacing, or a new feature.
  3. When something is not working, describe what you expected and what happened instead.
  4. Open 05-follow-up-prompts.md for ready-made prompts covering accessibility, mobile layout, images, bug fixes, the README, and your demo script.

7Test your app

  • Every button and interactive feature works as expected
  • There are no error messages in the browser console
  • The text is easy to read and free of typos
  • The layout works on a narrow, phone-sized window
  • You can use the app with only a keyboard

8Publish with GitHub Pages

  1. In Codespaces, commit and sync your changes using the Source Control tab.
  2. Go to your repository on GitHub.com.
  3. Select Settings → Pages.
  4. Under Build and deployment, choose Deploy from a branch.
  5. Set the branch to main and the folder to / (root), then select Save.
  6. Wait a minute, then refresh the Pages settings screen to see your live link.

Your app will be published at: https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/
